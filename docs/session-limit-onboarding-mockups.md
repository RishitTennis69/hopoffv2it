# Session Limit Visual Mockups

These are quick ASCII mockups for the session-limit directions we have discussed.

## Vertical Stack of Scroll Windows

Best when we want each session to feel like a separate "window" of allowed scrolling.

```text
+-----------------------------------+
| Session limits                    |
|                                   |
| A 90 min limit becomes a few      |
| separate scroll windows.          |
|                                   |
| +-----------------------------+   |
| | Scroll window 1             |   |
| | 30 min                      |   |
| +-----------------------------+   |
|                                   |
| +-----------------------------+   |
| | Scroll window 2             |   |
| | 30 min                      |   |
| +-----------------------------+   |
|                                   |
| +-----------------------------+   |
| | Scroll window 3             |   |
| | 30 min                      |   |
| +-----------------------------+   |
|                                   |
|         [ 2 parts ] [ 3 parts ]   |
+-----------------------------------+
```

## Daily Allowance Bar That Splits Apart

Best when we want the daily total to stay visually central, then split into parts as the toggle changes.

```text
+-----------------------------------+
| Session limits                    |
|                                   |
| Daily allowance                   |
| [============= 90 min ===========]|
|                                   |
| 2 parts                           |
| [========= 45 min =========]      |
| [========= 45 min =========]      |
|                                   |
| 3 parts                           |
| [===== 30 min =====]              |
| [===== 30 min =====]              |
| [===== 30 min =====]              |
|                                   |
|         [ 2 parts ] [ 3 parts ]   |
+-----------------------------------+
```

## Short Read

The stack feels more "behavioral" and intervention-like.

The allowance bar feels more mathematical and easier to understand at a glance.

If we want something that feels a little more premium and less dashboard-y, the vertical stack is the stronger direction.
